# Actualizar Keepr a 0.18 desde GitHub web

1. Descomprime keepr-actualizacion-0.18.zip.
2. Abre tu repositorio keepr y vuelve a la raíz (donde está package.json).
3. Add file → Upload files. Arrastra los archivos y carpetas contenidos en el ZIP, conservando sus nombres y rutas. No arrastres el ZIP ni una carpeta que los envuelva.
4. Commit changes directamente en main.
5. Render desplegará automáticamente si Auto-Deploy sigue en On Commit. Espera Deploy succeeded / Live.
6. Recarga Keepr en el celular. Si conserva la versión anterior, cierra esa pestaña y abre de nuevo tu enlace de Render. No borres los datos del navegador.

No vuelvas a subir models ni sus tres partes. Conserva los comandos y variables de Render actuales. No necesitas añadir claves para Crear receta.

Incluye: iconos para los 82 alimentos, selección inicial de todos los resultados, fechas adaptadas a móvil, textos para clientes y recetas por reglas con el inventario.

El ZIP completo es una alternativa para una instalación nueva. Esta actualización no publica nada por sí misma.
